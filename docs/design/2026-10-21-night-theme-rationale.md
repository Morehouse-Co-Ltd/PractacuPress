# 夜航主题设计记录

夜航是 Practacu Press 的深色杂志主题，目标是让「以图叙事」的创作者有一个和纸白阅读体验不同的选择，同时不改变内容模型。

## 设计目标

- 深色是主模式，浅色不是反相，而是重新配的一套纸白令牌。
- 首页用大图、色块和紧凑榜单建立第一眼的重心。
- 文章页用封面图和标题叠字形成进入感，正文仍保持可读的宽度。
- 卡片语言统一：12–16px 圆角、1px 描边、悬停轻微上浮。
- 所有视觉都通过主题令牌输出，不硬编码组件级颜色。

## 首页结构

1. 双卡首屏：左侧大卡放标题、说明和搜索；右侧是紧凑热门榜或欢迎卡。
2. 分类胶囊：用颜色建立分区记忆。
3. 置顶/热门封面网格：大格子显示更多信息，小格子只保留标题。
4. 双列封面文章卡 + 右侧粘性栏：作者、统计、标签、归档。
5. 窄屏下侧栏回到主栏下方，保持内容顺序。

## 文章页

- 全幅封面头：图片铺满，标题与摘要压在深色遮罩上。
- 正文区顶部保留同图模糊层，让封面与正文过渡。
- 桌面双栏：正文 + 右侧作者/分类/热门/标签。
- 窄屏收为单栏。
- 这是夜航专属的文章结构；白昼使用不同的白底分栏头与单栏正文。

## 边界

- 夜航只处理版式、颜色和组件外观，不改变文章、评论、权限或存储。
- 页头样式、导航内容、页脚内容都由站点设置提供，主题只负责视觉。
- 不复制任何第三方站点的名称、文案、插画、头像或图标素材。
