# 两套内置主题的结构差异

这份文档只回答一件事：**为什么两套主题不是同一套版式换色。**

> 2026-11 起「白昼」不再是独立主题；它的明亮纸面并入夜航的浅色重配。
> 旧配置里的 `daylight` 版式仍可读取，但不再出现在主题库、安装向导与新建主题的选项里。
> 背景见 [2026-11-09-theme-refresh](2026-11-09-theme-refresh.md)。

| | 原版 / Classic | 夜航 / Night |
| --- | --- | --- |
| 类型 | 纸白编辑排版 | 冷石墨杂志（浅色为冷白纸面） |
| 布局变体 | `classic` | `bento` |
| 主色 | 墨绿 | 电光蓝 |
| 字体 | 衬线标题 | 衬线标题 |
| 页头 | 单行下划线 Tab | 单行居中胶囊 Tab |
| 首页主结构 | Hero + 内容流 + 侧栏 | 石墨 Hero + 热门榜 + 瓷片区 + 侧栏 |
| 首页组件 | `classic-hero` / `feed` / `join-band` | `bento-hero` / `spotlight` / `post-grid` 等 `nf-*` 组件 |
| 首页数据密度 | 单栏长列表 | 图像密集的双栏 / 网格 |
| 文章页头 | 常规标题、居中 | 全幅深色封面、标题叠图 |
| 文章正文 | 居中阅读列 | 居中阅读列 + 左侧悬浮目录 |
| 页脚 | 居中报头尾 | 居中报头尾（深色令牌） |
| 圆角 | 小圆角 | 12–16px 卡片 |
| 动效 | 轻 | 悬停上浮、封面变化 |

## 代码边界

- Classic 的首页组件在 `components/blocks/Classic.tsx`，样式在 `styles.css` 的基础段落。
- Night 的首页组件在 `components/blocks/Nightflight.tsx`，样式主要限定在 `[data-variant='bento']`。
- 白昼的旧版式仍保留 `components/blocks/Daylight.tsx` 与 `styles/daylightTheme.css`，只服务旧配置；新站点不能再选它。
- 文章页共用 `ContentDetail` 的数据与交互；右侧栏已移除，正文统一居中，左侧目录由 `FloatingToc` 渲染。

## 避免混淆的规则

1. 新增主题先确定一个与现有主题不同的**首页骨架**，不能只改变量。
2. 主题自己的首页主组件必须使用独立类名前缀；不得复制其他主题的组件类名。
3. 文章页至少要有一项结构差异：页头形态、正文栏数、侧栏位置或页面级组件。
4. 页头与页脚至少各有一项结构差异，而不是只换颜色。
5. 设计文档只描述产品自己的设计意图，不把任何第三方站点写成参考来源。
6. 不复制第三方站点的名称、文案、图片或素材。

## 验收信号

- Classic：存在 `.hero`、`.feed-layout`。
- Night：存在 `.nf-hero`、`.pp-screen-bento`，文章页存在左侧 `.article-float-toc`（宽屏）。
- 两套主题都使用 720px 居中正文列；文章页正文的 `x` 与视口中心对称。
- 两套主题的页脚都是居中报头尾，品牌标记沿用 `.brand-mark`。
