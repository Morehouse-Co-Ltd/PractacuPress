# 页面编排器重做 · 设计规格

日期：2026-10-24  
状态：已确认，待实现  
范围：`apps/web` 的页面编排、区块渲染、后台导航；不包含完整的「外观主题中心」重构。

## 1. 背景

当前主题工坊把主题令牌、首页编排、思维链、页面模板放在一个页面里，编排器又只有平铺区块和上下移动按钮。用户无法：

- 在真实前台页面上实时看到修改结果；
- 通过拖拽调整顺序或把组件放进分栏；
- 使用真正的嵌套布局；
- 给文本块写局部 CSS；
- 方便地添加图片、视频、网站卡片和幻灯片。

同时，外观页与工坊的职责重叠，后台会被前台暗色主题一起染黑。本轮先解决**页面编排**，外观主题中心留到下一阶段。

## 2. 目标与非目标

### 目标

1. 把「主题工坊」重做为「页面编排」，采用左树、中预览、右属性的三栏结构。
2. 支持递归区块树，任意层级嵌套（实际限制 8 层、200 个区块）。
3. 支持拖拽排序、拖入容器、拖入分栏列；保留按钮操作作为降级路径。
4. 支持真实前台 iframe 实时预览、点击预览选中区块、选中区块滚动高亮、桌面/平板/手机宽度。
5. 新增分栏、文本（带作用域 CSS）、图片、视频、网站、幻灯片区块。
6. 把原「主题令牌」编辑能力迁到「外观 → 高级主题」，不在编排器里重复。
7. 后台固定浅色，前台暗色主题只作用于站点前台和预览。

### 非目标（下一阶段）

- 主题库、两套内置主题卡片、主题文件导入/导出入口重做；
- 外观页的整体信息架构重做；
- 可见即所得的任意绝对定位画布；
- 第三方页面构建器级别的历史版本、协作编辑、模板市场。

## 3. 信息架构

- `/admin/theme` 保留，页面标题改为「页面编排」。
- 导航仍位于「站点设置」组，名称改为「页面编排」。
- 页面标签页：
  - `页面编排`：新的三栏编辑器；
  - `思维链`：保留现有 ChainEditor；
  - `页面模板`：保留现有 PAGE_TEMPLATES。
- 「主题令牌」从工坊移除，迁入 `/admin/appearance` 的「高级主题」区块。
- 编排目标继续支持「首页」和自定义页面；在顶部下拉切换。
- 编辑自定义页面时，预览 iframe 加载对应页面地址；首页加载 `/`。

## 4. 数据模型

### BlockInstance 扩展

```ts
export interface BlockInstance {
  id: string;
  type: string;
  title: string;
  props: Record<string, string | number | boolean>;
  animation: BlockAnimation;
  hidden: boolean;
  area?: BlockArea;
  /** 递归子区块，仅容器类区块使用。 */
  children?: BlockInstance[];
  /** 在分栏容器里的列号，从 1 开始；根级区块忽略。 */
  column?: number;
}
```

### 归一化

`normalizeBlock` 递归处理 `children`：

- 最大深度 8，整棵树最多 200 个区块；
- 子区块 id 必须唯一，重复时重新生成；
- `column` 夹在 1–4；
- 旧配置没有 `children` 时保持原样，不迁移。

### 渲染

- `BlockView` 递归渲染 `children`。
- 分栏容器渲染 2–4 列，按 `column` 分组；子区块可以继续是分栏容器。
- 根级 bento 的 `area` 分栏逻辑只作用于顶层，容器内部按列布局。
- 所有嵌套区块都输出 `data-pp-block`，思维链、动画和预览桥接继续有效。

## 5. 三栏编辑器

### 左栏

- 组件库：按「布局 / 内容 / 媒体 / 动态」分组，可拖入树和预览。
- 递归层级树：
  - 行内显示类型、标题、动画、隐藏状态；
  - 拖拽手柄排序；
  - 拖到分栏区块的行上时，显示列投放区；
  - 每行有上移/下移/隐藏/删除；
  - 容器行展开显示各列子区块和「添加子区块」。
- 分栏区块被选中时，右栏显示每列的子区块列表和投放区。

### 中栏

- 真实前台 iframe，默认桌面宽度，可切平板/手机。
- 预览地址由目标页决定。
- 编辑器通过 `postMessage` 接收预览点击事件；预览侧通过 `data-pp-block` 找到区块 id。
- 选中区块时向 iframe 发送高亮消息，iframe 滚动到该区块并加临时高亮边框。
- 配置变化写入本地安装配置；iframe 监听 `storage` 事件更新自身配置，无需刷新。
- 提供「新窗口打开」和刷新预览。

### 右栏

- 区块标题、动画、落位/列号；
- schema 自动生成的属性表单；
- 文本块额外显示「作用域 CSS」；
- 分栏块额外显示列数与子区块管理；
- 底部：重置属性、删除区块。

### 编辑操作

- 300ms 防抖合并修改，避免每次按键都广播预览。
- 撤销/重做栈，最多 50 步，覆盖添加、删除、移动、属性修改、嵌套。
- 拖拽和按钮操作共用同一组树操作函数。

## 6. 新增区块

| 类型 | 能力 |
| --- | --- |
| `columns` | 2/3/4 栏容器，可嵌套，子区块按列号分布 |
| `text` | 眉题、标题、正文、对齐、最大宽度、作用域 CSS |
| `image` | 图片地址、替代文字、说明、链接、比例、裁剪 |
| `video` | MP4/WebM 地址、封面、标题、说明 |
| `website` | 网站卡片或 iframe 嵌入，标题、描述、封面、URL、高度 |
| `slideshow` | 手动幻灯片（图片、标题、说明、链接），自动轮播、箭头、圆点、悬停暂停 |

文本作用域 CSS：

- 输入是声明式 CSS，例如 `font-size: 18px; letter-spacing: .02em;`；
- 解析为 React 内联样式，只允许 `[a-z-]+` 属性名；
- 拒绝 `{`、`}`、`<`、`>`、`@`、`expression`、`javascript:`、`url(`；
- 不生成全局 `<style>`，因此不会污染其他区块。

网站 iframe：

- 只接受 `http(s)` 地址；
- 使用 `loading="lazy"`、`referrerPolicy="no-referrer"`、`sandbox`；
- 用户明确选择 iframe 模式才渲染。

## 7. 预览桥接

新增一个只在 iframe 中启用的 `PreviewBridge`：

- 监听站点前台内 `[data-pp-block]` 的点击，向 `window.parent` 发送 `{ type: 'pp:preview-select', blockId }`；
- 接收 `{ type: 'pp:preview-focus', blockId }`，滚动并高亮对应区块；
- 正常浏览器访问不产生可见变化。

父页面：

- 监听 `message`，校验 `event.origin === window.location.origin`；
- 选中联动、设备宽度切换、刷新按钮；
- iframe 的 `src` 使用目标页地址。

配置同步：

- `App` 监听 `storage` 事件，读取最新安装配置并更新 React 状态；
- 编辑器写入配置后，iframe 自动更新；
- 兼容真实后端模式与演示模式。

## 8. 主题与暗色后台

- 原「主题令牌」面板整体迁入外观页的「高级主题」折叠区。
- 后台通过 `data-surface="admin"` 固定使用纸白浅色令牌；前台暗色主题不再改变后台颜色。
- 预览 iframe 属于前台，继续使用主题明暗模式。

## 10. 验收标准

1. 旧首页和旧自定义页面打开不白屏，现有测试通过。
2. 可以新建 2/3/4 栏容器，并把区块拖进任意列；容器可再放入容器。
3. 拖拽排序与按钮排序结果一致；刷新页面后顺序和嵌套保持。
4. 预览 iframe 显示真实前台；修改标题/颜色/动画后无需手动刷新即可看到。
5. 点击预览区块会选中左侧对应节点；选中左侧节点会滚动并高亮预览。
6. 文本块作用域 CSS 只影响自身，不改变其他区块。
7. 图片、视频、网站卡片/iframe、幻灯片可以添加并正常渲染。
8. 思维链仍可指向嵌套区块并执行显示/隐藏/滚动。
9. 桌面、平板、手机三档预览无横向溢出；后台始终浅色。
10. typecheck、build、现有单测与新增 Playwright 验收通过。

## 12. 风险与取舍

- **无限嵌套**让树操作和拖拽命中更复杂：用单一递归树操作模块集中处理，编辑器和渲染器共用。
- **iframe 预览**受跨域、登录态和页面脚本影响：本轮只预览同源站点，外部网站只作为区块内容，不作为预览目标。
- **作用域 CSS** 不做完整 CSS 解析器，只支持安全声明；复杂样式仍可在「外观 → 自定义 CSS」完成。
- **主题中心**不在本轮：仅迁移令牌，主题库、导入和外观实时预览留到下一阶段，避免一次改动过大。
