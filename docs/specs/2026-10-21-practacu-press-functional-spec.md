## 1. 范围与角色

### 1.1 产品范围

Practacu Press 是**多站点内容系统**，个人博客是它的单站点部署形态。本规格覆盖：

- 阅读端：访客可见的全部页面与交互
- 创作端：文章、页面、媒体、发布流程
- 管理端：站点、成员、审核、设置、外观
- 系统能力：账号、通知、搜索、订阅、统计、备份

**不在本规格内**：付费、广告、积分、插件市场（见第 6 章）；移动端 App；多租户计费。

### 1.2 角色

| 角色 | 定义 | 核心权限 |
| --- | --- | --- |
| 访客 | 未登录 | 读公开站点、搜索、看评论（不可写） |
| 成员 | 站点注册用户 | 评论、点赞、收藏、关注、私信、个人中心 |
| 作者 | 可创作角色 | 成员权限 + 创建/编辑自己的内容、上传媒体 |
| 编辑 | 审核角色 | 作者权限 + 审核他人内容、处理举报 |
| 站点管理员 | 站点所有者 | 站点设置、成员管理、外观、全部内容 |
| 平台管理员 | 部署方 | 跨站点管理、创建站点、授予管理员 |

权限矩阵以 `internal/site` 的 4 角色 × 4 动作实现为准；本规格不重复定义矩阵值，只引用。

## 8. 明确不做（Out of Scope）

| 需求 | 原章节 | 理由 |
| --- | --- | --- |
| 付费阅读、订单、退款、发票 | 2.2.8 | 支付资质、税务、防盗链、回调验签四项独立工程 |
| 付费下载 | 2.2.8 | 同上，另需病毒扫描与断点续传 |
| 打赏 | 2.2.9 | 依赖支付通道 |
| 广告位与 A/B 测试 | 2.6 | 与"轻量"冲突；定向与统计另需链路 |
| 积分与等级 | 2.8 | 流水表 + 定时任务 + 权益判定，复杂度不匹配 |
| 插件市场 | 2.2.12 | 代码执行面无法收敛 |
| 在线模板编辑 / 子主题 | 2.2.11 | 等于开放代码执行；模板语法成为永久兼容负担 |
| 匿名评论 | 2.2.1 | 需验证码、频率限制、垃圾识别三条链路 |
| 多平台同步发布 | 2.3.5 | 每个平台一套 API 与格式适配 |
| Windows 安装包 | 第五章 | 需代码签名与安装器测试 |
| 短信验证码 | 2.2.1 | 需服务商资质与费用 |
| 内容伪原创 / 禁止右键 | 2.11 | 损害可访问性与 SEO，收益为负 |

> 以上条目不是"暂缓"，是**产品边界**。新增需先修订本规格并重新估算。
