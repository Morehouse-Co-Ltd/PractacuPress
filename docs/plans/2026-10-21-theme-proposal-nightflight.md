## 0. 摘要

参考站是一套完成度很高的深色博客皮肤：**Bento 网格 + 大图封面 + 胶囊导航 + 渐变卡片**，视觉上像一本会动的杂志，而不是传统的文章列表页。

本企划要做的不是"复刻它"，而是把这套语言**抽象成 Practacu Press 可配置的第二套主题**：

- 颜色、字体、圆角、间距全部令牌化，可被现有 `themeCss()` 输出；
- 结构层新增一个 `layout.variant = bento` 变体，与现有编辑排版风（`classic`）并存；
- 明确依赖后端字段（封面、标签、阅读量），避免"主题先行、数据缺失"导致大面积空占位。

**一句话：给"以图叙事"的创作者一套深色杂志皮肤，同时不破坏现有的极简阅读体验。**

## 1. 背景与目标

### 1.1 为什么需要第二套主题

现有默认主题「纸白」是**编辑排版风**：白底、衬线标题、窄栏、强留白，适合长文与技术笔记。它的问题不是不好看，而是**只服务一种内容形态**。

参考站证明了另一种需求真实存在：创作者用大量高质量配图（摄影、插画、截图）组织内容，希望首页像作品集而非目录。这类站点用「纸白」会显得空、图片被窄栏压小、首屏没有视觉重心。

因此需要一套**画廊型**主题，二者按内容形态二选一，而不是互相替代。

### 1.2 参考站做对了什么

| 观察 | 为什么有效 |
| --- | --- |
| 首屏左侧一块纯黑标题卡，右侧一块浅色渐变卡 | 两个焦点形成张力，一屏讲完"我是谁 + 这里有什么" |
| 三枚高饱和渐变胶囊（学习日记/日常/关于我） | 用颜色而非文字建立分类记忆，点击目标极大 |
| 内容区 2 列大图卡片 + 右侧 320px 固定栏 | 图片获得足够面积，侧栏承载"人"的存在感 |
| 卡片几乎不用阴影，只用 1px 描边 + 3 级背景明度差 | 深色下阴影几乎不可见，描边才是分层手段 |
| 文章页用封面模糊图做 hero，正文卡片上浮压住它 | 单张封面同时承担氛围与信息，滚动时有"进入文章"的仪式感 |
| 关于页是 Bento 矩阵（自我介绍/技能墙/时间线/统计/地图） | 把"关于我"从一段文字变成可浏览的信息设计 |

### 1.3 参考站不该照搬的部分

| 问题 | 我们的处理 |
| --- | --- |
| 首屏信息密度过高（标题、5 个悬浮图标、渐变卡、三个胶囊、标签页） | 收敛为「标题卡 + 一张精选 + 分类胶囊」，去掉悬浮图标群 |
| 站点带有一批非内容型功能页（`/music`、`/album`、`/air-conditioner`）与快捷键中控台 | 全部不做，见第 13 章 |
| 装饰字体（ZhuZiAYuanJWD）与 LED 数字字体用于正文场景 | 只允许出现在统计数字与站点标语，正文一律系统字体 |
| 作者卡渐变随页面变化（文章页偏绿、归档页偏紫） | 作者卡渐变只跟随全局主色，不随页面换色 |

## 2. 参考站拆解（实测）

### 2.1 信息架构

```
顶部胶囊导航   站点标识 ｜ 文库 · 友链 · 我的 · 关于 ｜ 用户 · 留言 · 搜索 · 菜单
英雄区         左：纯黑标题卡（大标题 + 域名）   右：渐变欢迎卡（脚本字 Hello + 副标题 + 行动按钮）
分类胶囊       学习日记 / 日常 / 关于我（渐变填充）
内容区         标签页（学习日记 · 摸鱼日常 · 日常）→ 双列文章卡 + 右侧栏
右侧栏         作者卡（渐变底 + 头像 + 社交图标）· 公众号卡 · 标签/榜单 · 站点统计
页脚           导航 · 关于 · 关注（三栏）+ 运行时长 + CC 协议 + 访客数 + 回到顶部
```

页面路由：`/`、`/posts/{slug}`、`/archives`、`/categories`、`/categories/{name}`、`/tags`、`/tags/{name}`、`/about`、`/link`、`/equipment`、`/music`、`/album`、`/recentcomments`。

### 2.2 布局栅格

| 断点 | 内容宽度 | 主区 | 右栏 | 卡片列数 |
| --- | --- | --- | --- | --- |
| ≥ 1280px | 约 1400px（左右各 24px 边距） | 自适应 | 320px 固定 | 2 |
| 768–1279px | 100% − 48px | 自适应 | 320px | 2（图片变窄） |
| < 768px | 100% − 32px | 单列 | 隐藏，内容下沉 | 1 |

移动端细节：分类胶囊变横向滚动 chips；导航收成「站点名 + 用户图标」；英雄区改为整块封面背景 + 标题叠加。

### 2.3 视觉令牌（从样式表实测）

**深色（站点默认）**

| 令牌 | 实测值 | 用途 |
| --- | --- | --- |
| `--background` | `#18171d` | 页面底色（带一点紫的暖黑，不是纯黑） |
| `--card` | `#1d1e22` | 卡片 |
| `--muted` | `#21232a` | 次级块、输入框 |
| `--secondary` | `#30343f` | 三级块、标签底 |
| `--border` | `#3d3d3f` | 1px 描边 |
| `--foreground` | `#f7f7fa` | 主文字 |
| `--muted-foreground` | `#a1a2b8` | 次要文字（偏紫的灰） |
| `--primary` | `#c4b5fd` | 主色（站点运行时覆盖值，薰衣草紫） |
| `--primary-foreground` | `#1e1b2e` | 主色上的文字 |

**浅色（同一套变量的另一组值）**

| 令牌 | 实测值 |
| --- | --- |
| `--background` | `#f7f9fe` |
| `--card` | `#ffffff` |
| `--border` | `#e3e8f7` |
| `--foreground` | `#363636` |
| `--primary` | `#163bf2`（电光蓝） |

**辅助色**（深/浅两套）：蓝 `#0084ff` / `#3e86f6`、红 `#ff3842` / `#d80020`、粉 `#d44040` / `#ff7c7c`、绿 `#3e9f50` / `#57bd6a`、黄 `#ffc93e` / `#c28b00`、橙 `#ff953e` / `#e38100`、紫 `#7a60d2`。

> **关键发现**：样式表里 `.dark` 的主色是琥珀金 `#dfa621`，但站点在 `<html>` 上内联覆盖成了 `#c4b5fd`。说明**主色是可配置的**，深/浅两套皮肤各自只提供默认值。我们的主题也应遵循同样思路：主色可换，结构不变。

**圆角**（按出现频次）：12px（卡片主力，53 次）、8px（小控件，51 次）、50%/50px（头像与胶囊）、16–20px（hero 大卡）。

**动效**：`all .3s` 为主（76 次），hover 类 `.2s`（22 次），缓动 `cubic-bezier(.4,0,.2,1)`。

**字体**：正文为系统无衬线 `PingFang SC / Hiragino Sans GB / Microsoft YaHei`；代码 `Source Code Pro`；装饰字体仅用于标语与数字。标题靠**字重 + 字号**建立层级（hero 约 56–64px，文章标题 32–40px），不靠特殊字体。

### 2.4 组件语言

| 组件 | 做法 |
| --- | --- |
| 顶部导航 | 悬浮胶囊，半透明深色底 + 1px 描边，距顶部 16px，不贴边 |
| 文章卡 | 封面 16:9、圆角 12px；下方标签（彩色小字）+ 标题（16–18px，两行截断）+ meta（日期/阅读数） |
| 分类胶囊 | 渐变填充（蓝/橙/绿），圆角 999px，图标 + 文字，高度约 44px |
| 作者卡 | 渐变底（随主色），圆形头像 + 状态点 + 昵称 + 一言 + 三个社交图标 |
| 侧栏统计 | 键值列表，数字右对齐，用等宽或 LED 字体突出 |
| 文章 hero | 封面图 `filter: blur(24px)` + 深色遮罩，标题白字压在图上 |
| 正文卡 | 上浮 80–120px 压住 hero，圆角 16px，内部最大行宽约 760px |
| 页脚 | 三栏链接 + 一条底部信息条，字号 12–13px，颜色 `--muted-foreground` |

### 2.5 交互与快捷键

参考站有一套完整的键盘体系：`Shift+K` 快捷键面板、`Shift+A` 中控台、`Shift+D` 深浅切换、`Shift+S` 搜索、`Shift+R` 随机文章、`Shift+H` 回首页、`Shift+L` 友链、`Shift+P` 关于、`Shift+I` 右键菜单切换。

**取舍**：只保留 4 个高频项 —— `Shift+K` 快捷键面板、`Shift+D` 深浅切换、`Shift+S` 搜索、`Shift+H` 回首页。中控台与右键菜单替换属于"炫技型"功能，增加维护面但不增加阅读价值。

## 3. 主题定位

### 3.1 一句话

**「夜航」是一套深色优先、以封面图组织内容的杂志式主题；它把首页当封面、把文章页当跨页，适合图片密度高、更新频率中等的个人站。**

### 3.2 目标用户与内容形态

| 维度 | 适配 | 不适配 |
| --- | --- | --- |
| 内容 | 摄影、插画、设计、硬件开箱、旅行、生活随笔 | 纯文字技术长文、API 文档、大量表格 |
| 配图 | 每篇有 16:9 封面，图质较高 | 无封面、封面比例混乱 |
| 更新 | 每周 1–5 篇 | 日更 10 篇以上（双列信息流会过长） |
| 读者 | 浏览型、视觉驱动 | 检索型、需要快速扫标题 |

不适配的场景由「纸白」承接——这正是保留两套主题的意义。

### 3.3 与「纸白」的关系

| 维度 | 纸白（现有） | 夜航（新增） |
| --- | --- | --- |
| 隐喻 | 纸 | 屏幕/暗房 |
| 底色 | 白 | 暖黑 `#18171d` |
| 标题字体 | 衬线 | 无衬线，靠字重 |
| 首页 | 单列列表 | 双列大图 + 右栏 |
| 正文宽度 | 720px | 760px |
| 图片地位 | 附属 | 主体 |
| 互动元素 | 弱化 | 作者卡/统计前置 |

两套主题共享同一套数据与路由，切换只改 `layout.variant` + 令牌，不改组件树结构（详见 7.2）。

## 4. 设计原则

1. **深色是主角，浅色是重配而非反色。** 浅色版不是把 `#18171d` 反过来，而是重新给一组"冷白纸"值（`#f7f9fe`），否则会得到一片刺眼的纯白。
2. **分层靠线，不靠影。** 深色下阴影几乎不可见；用 `background → card → secondary` 三级明度 + 1px `border` 建立层次。全站只允许 hero 卡使用弥散阴影。
3. **一屏一个焦点。** 首页首屏只有"标题卡 + 精选内容"，不叠加第三个视觉重心。
4. **颜色是索引，不是装饰。** 分类色只出现在胶囊与标签；文章卡本身保持中性，避免首页变成调色盘。
5. **图不抢字。** 封面之上必有遮罩或渐变；标题与正文的对比度不低于 7:1（深色）/ 4.5:1（浅色）。

## 5. 设计令牌

### 5.1 颜色

**深色（默认）**

```css
--bg:            #18171d;   /* 页面底 */
--bg-subtle:     #1d1e22;   /* 卡片 */
--bg-sunken:     #21232a;   /* 输入框、代码块 */
--ink:           #f7f7fa;   /* 主文字 */
--ink-soft:      #d6d6e0;   /* 正文 */
--muted:         #a1a2b8;   /* 次要文字 */
--faint:         #6f7085;   /* 时间、计数 */
--line:          #2c2d36;   /* 分隔线 */
--line-strong:   #3d3d3f;   /* 卡片描边 */
--accent:        #c4b5fd;   /* 主色：薰衣草 */
--accent-ink:    #1e1b2e;   /* 主色上的文字 */
--accent-soft:   #c4b5fd1f; /* 主色 12% 底 */
```

**浅色**

```css
--bg:            #f7f9fe;
--bg-subtle:     #ffffff;
--bg-sunken:     #eef1f9;
--ink:           #17181d;
--ink-soft:      #363636;
--muted:         #5b5d6b;
--faint:         #8a8c9b;
--line:          #e6eaf5;
--line-strong:   #d8ddec;
--accent:        #163bf2;
--accent-ink:    #ffffff;
--accent-soft:   #163bf214;
```

**分类色板**（两套模式各一份，仅用于胶囊/标签）

| 名称 | 深色 | 浅色 | 渐变（深色） |
| --- | --- | --- | --- |
| 学习 | `#5b8cff` | `#3e86f6` | `linear-gradient(135deg,#4f7cff,#7aa2ff)` |
| 日常 | `#ff9a5a` | `#e38100` | `linear-gradient(135deg,#ff8a4c,#ffb27a)` |
| 关于 | `#4fd1a5` | `#12a37a` | `linear-gradient(135deg,#3ecf9a,#7ee7c4)` |
| 随笔 | `#c4b5fd` | `#7a60d2` | `linear-gradient(135deg,#a78bfa,#d8ccff)` |

> 渐变色只允许出现在：分类胶囊、hero 右侧卡、作者卡底。其他任何地方使用渐变都视为越界。

### 5.2 字体与字号阶梯

```css
--font-sans: "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", system-ui, sans-serif;
--font-mono: "Source Code Pro", "Cascadia Code", Consolas, monospace;
```

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 56 / 1.1 | 800 | 首页 hero 标题（移动端 40） |
| H1 | 36 / 1.25 | 700 | 文章标题（移动端 28） |
| H2 | 26 / 1.35 | 700 | 章节标题 |
| H3 | 20 / 1.45 | 600 | 小节 |
| Body | 17 / 1.85 | 400 | 正文（可在设置中 16–19 调节） |
| Meta | 13 / 1.5 | 400 | 时间、阅读量、标签 |
| Caption | 12 / 1.4 | 500 | 图片说明、页脚 |

标题一律 `letter-spacing: -0.01em`；中文正文 `text-align: justify` 仅在 ≥ 768px 启用。

### 5.3 间距、圆角、描边、阴影

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px; --space-4: 16px;
--space-5: 24px; --space-6: 32px; --space-7: 48px; --space-8: 64px;

--r-sm: 8px;    /* 标签、输入框 */
--r-md: 12px;   /* 卡片、封面 */
--r-lg: 16px;   /* hero 卡、正文卡 */
--r-pill: 999px;

--border: 1px solid var(--line-strong);
--shadow-hero: 0 24px 60px -30px rgb(0 0 0 / .65);
```

**纪律**：除 hero 与浮层外，任何元素不得使用 `box-shadow`；卡片一律 `background + border`。

### 5.4 断点与栅格

| 断点 | 宽度 | 主区 | 右栏 | 间距 |
| --- | --- | --- | --- | --- |
| `xl` | ≥ 1280 | `minmax(0,1fr)` ×2 | 320px | 24px |
| `lg` | 1024–1279 | 2 列 | 300px | 20px |
| `md` | 768–1023 | 2 列 | 隐藏 | 16px |
| `sm` | < 768 | 1 列 | 隐藏 | 12px |

容器最大宽度 1400px，左右内边距 24px（移动端 16px）。栅格用 `display:grid; grid-template-columns: repeat(2,minmax(0,1fr)) 320px; gap:24px`。

### 5.5 与现有主题系统的映射

现有 `themeCss()` 只输出 `--bg / --ink / --accent` 及其派生色，**结构（单列/双列、是否有右栏）不在令牌范围内**。因此本主题分两层落地：

| 层 | 现状 | 本主题需要 |
| --- | --- | --- |
| 颜色层 | `ThemeSettings`（preset/background/ink/accent/heading_font/body_size/content_width） | 新增两个预设：`night`（深）、`dawn`（浅）；扩展 `ThemePreset` 增加 `mode: 'light'\|'dark'` 与 `bg_subtle`（否则深色卡片无法与底色区分） |
| 结构层 | 固定单列 + 可选侧栏（现有 LayoutSettings） | 新增 `layout.variant: 'classic' \| 'bento'`，由页面组件读取并切换栅格与卡片形态 |

**结论：本主题不是"再加一个配色"，而是一次结构扩展。** 这一点必须在排期里体现（第 11 章 T0 的任务就是补这两个抽象层，而不是调颜色）。

## 6. 页面设计

### 6.1 首页

```
┌──────────────────────────── 1400 ────────────────────────────┐
│  导航胶囊（悬浮，距顶 16）                                      │
│  ┌──────────────────────┐  ┌──────────────────────────────┐  │
│  │ 站点标语（Display）    │  │ 渐变卡：欢迎语 + 一句简介      │  │
│  │ 域名 / 小字           │  │ + 「最新文章」按钮             │  │
│  └──────────────────────┘  └──────────────────────────────┘  │
│  [分类胶囊] [分类胶囊] [分类胶囊]                                │
│  ┌────────────┐ ┌────────────┐ ┌──────────┐                  │
│  │ 文章卡 16:9 │ │ 文章卡 16:9 │ │ 作者卡    │                  │
│  ├────────────┤ ├────────────┤ │ 标签云    │                  │
│  │ 文章卡      │ │ 文章卡      │ │ 站点统计  │                  │
│  └────────────┘ └────────────┘ └──────────┘                  │
└──────────────────────────────────────────────────────────────┘
```

- 左侧标题卡：纯 `--bg-sunken` 背景，无图；标题用 Display 级，最多两行；下方一行域名小字。
- 右侧渐变卡：由主色生成 `linear-gradient(135deg, accent, accent 40%, transparent)`，文字 `--accent-ink`。
- 分类胶囊：取前 3 个分类，圆角 pill，高 44px，图标 + 名称 + 文章数。
- 文章卡：封面 16:9 + 标签行 + 标题（2 行截断）+ meta（日期 · 阅读数）。
- 右栏：作者卡（渐变底）→ 标签云 → 站点统计（文章数/建站天数/总字数）。
- 无封面降级：用 `linear-gradient(135deg, accent-soft, bg-subtle)` + 标题首字，不允许出现灰色破图。

### 6.2 文章页

- hero：封面图 `width:100%; height:420px; object-fit:cover; filter:blur(28px) brightness(.45)`，叠加轻微暗角；无封面时用主色渐变。
- 面包屑与标签在 hero 左上；标题 40px；meta 一行（字数 · 阅读时长 · 日期 · 阅读量）。
- 正文卡：`margin-top:-96px`，`background: var(--bg-subtle)`，`border-radius:16px`，内边距 40px（移动端 20px），正文最大行宽 760px。
- 右侧栏：作者卡（sticky）→ 目录（sticky，滚动高亮）→ 相关文章。
- 文末：打赏/订阅/分享三按钮（沿用现有扩展），上下篇卡片，评论（社区模式）。
- 代码块：`--bg-sunken` 底 + 1px 描边，标题栏显示语言与复制按钮；不使用第三方高亮主题。

### 6.3 归档页

- 左卡：年份大标题 + 该年文章列表（缩略图 64×40 + 标题 + 标签 chips）。
- 右栏：标签云（按数量加权字号）→ 月份网格（年月 + 篇数）→ 站点统计。
- 年份吸顶，滚动时高亮当前年份。

### 6.4 分类 / 标签页

> 参考站的分类页只有标题 + 三个胶囊，没有列表——过于单薄。我们在保留胶囊入口的同时补上内容区。

- 顶部：标题 + 文章数 + 描述。
- 分类卡片：封面（可选）+ 名称 + 篇数，2 列。
- 标签云：字号 14–22px 随篇数线性映射，颜色 `--muted`，hover 变 `--accent`；不做 3D 球。

### 6.5 搜索

- 全屏浮层：`backdrop-filter: blur(12px)` + `rgba(0,0,0,.6)`，居中输入框（高度 56px，圆角 pill）。
- 输入即搜（防抖 300ms），结果列表最多 8 条，命中词高亮 `--accent`。
- 空态：显示"试试这些标签"（取前 6 个标签）。

### 6.6 关于页

Bento 矩阵，2 列不等高：

| 卡片 | 内容 |
| --- | --- |
| 身份卡 | 头像 + 昵称 + 一句话 + 3 个社交图标（**渐变底**） |
| 简介卡 | 3–5 行自我介绍，纯文字 |
| 技能卡 | 图标墙（最多 12 个，6×2），每个图标 56×56 圆角 12px |
| 时间线卡 | 3–6 个节点（年份 + 事件），左侧竖线 + 圆点 |
| 统计卡 | 文章数 / 建站天数 / 总字数 / 评论数 |
| 自定义卡 | Markdown 富文本，供用户自由放置（友链、设备清单等） |

移动端全部单列，顺序：身份 → 简介 → 统计 → 技能 → 时间线 → 自定义。

### 6.7 友链页

卡片墙（3 列 / 移动 1 列）：图标 40px + 名称 + 一句描述；hover 上浮 2px + 描边变 `--accent`。无 Logo 时用域名首字母色块。

### 6.8 404

整屏居中：大号「404」（Display 级，`--accent` 描边字），一行说明，两个按钮（回首页 / 随机一篇）。背景是与首页同款渐变，但透明度降到 20%。

## 8. 数据依赖

主题不是纯前端皮肤，下列字段缺失会直接导致空占位：

| 依赖 | 对应任务 | 缺失时的降级 |
| --- | --- | --- |
| 文章封面 `cover_asset_id` | P0-03 | 渐变占位 + 标题首字（可接受，但首页会失去"画廊感"） |
| 标签 `tags` | P0-05 | 隐藏标签行，卡片高度收缩 24px |
| 阅读量 `view_count` | P0-06 | 隐藏阅读数，仅显示日期 |
| 图片缩略图 / WebP | P1-06 | 直接用原图（首屏可能超预算） |
| 站点统计（文章数/字数/建站天数） | 新增只读接口或前端聚合 | 只显示文章数 |

**排期结论**：主题的完整形态必须排在 P0-03/P0-05/P0-06 之后；否则先做 T0 令牌与骨架，T1 首页等字段就绪再开。

## 9. 动效与可访问性

| 场景 | 动效 | 时长 / 缓动 |
| --- | --- | --- |
| 卡片 hover | `translateY(-2px)` + 描边变 `--accent` | 200ms `ease-out` |
| 分类胶囊 hover | 渐变位移 4px + 亮度 +6% | 200ms |
| 页面切换 | 内容区 `opacity 0→1` + `translateY(8px→0)` | 240ms |
| 深浅切换 | 颜色过渡（不加遮罩动画） | 300ms |
| 目录高亮 | 左侧 2px 指示条滑动 | 180ms |

可访问性硬要求：

- 正文对比度：深色 ≥ 7:1，浅色 ≥ 4.5:1（`--faint` 只用于非关键信息）。
- 所有可点击元素最小 44×44px；键盘焦点环 `2px solid var(--accent)` + `offset 2px`。
- `prefers-reduced-motion: reduce` 时关闭位移与模糊动画，只保留颜色变化。
- 图片必须有 `alt`；纯装饰图 `alt=""`。
- 深浅模式跟随系统，手动切换后持久化到 `localStorage`。

## 10. 性能预算

| 指标 | 目标 | 手段 |
| --- | --- | --- |
| 首屏 JS | ≤ 200KB（gzip） | 主题不引第三方库；搜索浮层动态 import |
| 首屏 LCP | ≤ 1.2s（4G 模拟） | 首图 `fetchpriority="high"` + 预加载；其余 lazy |
| 封面图 | ≤ 180KB/张 | 服务端生成 1280w WebP（P1-06）；`srcset` 三档 |
| 模糊 hero | 不额外请求 | 复用封面原图 + CSS `filter: blur()`，不做单独模糊图 |
| CLS | ≤ 0.05 | 卡片固定宽高比；字体 `font-display: swap` |
| 主题 CSS | ≤ 8KB | 全部走变量，不写组件级硬编码色 |

**反例警示**：参考站在内容之外还有音乐、相册、空调控制等独立页面与中控台，这些不属于阅读链路，我们不跟随，以免首屏与包体被非核心功能拖累。

## 12. 验收标准

**视觉**

- [ ] 首页在 1440 / 1024 / 390 三档下无横向滚动、无文字截断错误
- [ ] 深色下卡片与底色可区分（明度差 ≥ 3%，或存在 1px 描边）
- [ ] 全站主色只出现在交互态与强调处，统计硬编码颜色 = 0
- [ ] 无封面文章显示渐变占位，不出现破图或空白

**功能**

- [ ] 后台「外观」可一键在 classic / bento 间切换，且不影响已有文章数据
- [ ] 深浅模式切换后刷新仍保持；跟随系统时随系统变化
- [ ] 归档页按年分组正确，分类/标签页计数与列表一致

**质量**

- [ ] Lighthouse（移动端）：Performance ≥ 85、Accessibility ≥ 95、Best Practices ≥ 95、SEO ≥ 90
- [ ] 键盘可完成：导航 → 列表 → 文章 → 返回，焦点可见
- [ ] `prefers-reduced-motion` 下无位移动画
- [ ] 首屏 JS ≤ 200KB（gzip），主题 CSS ≤ 8KB

## 13. 风险与不做清单

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 深色下对比度不足，长文阅读疲劳 | 高 | 正文不用纯白（`#d6d6e0`），行高 1.85，最大行宽 760px |
| 封面质量参差导致首页观感崩塌 | 高 | 强制 16:9 裁切 + 无图降级；后台提示建议尺寸 1280×720 |
| 双列信息流使文章过多时页面过长 | 中 | 首屏最多 6 篇 + "加载更多"，不做无限滚动 |
| 新增 variant 影响 classic 样式 | 中 | 所有新样式限定 `[data-variant=bento]` 作用域；classic 回归截图对比 |
| 主题先于后端字段上线 | 中 | 见第 8 章排期约束；MVP 允许降级 |
| 被误认为参考站换皮 | 中 | 不复用素材与文案；结构上做了收敛（去悬浮图标、去小组件） |

**明确不做**：Live2D 看板娘、音乐播放器、天气、中控台、右键菜单替换、鼠标跟随特效、页面粒子背景、自动播放视频封面。
